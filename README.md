# Gamyx — Telegram Mini App Gaming Platform 🎮⚡

**Gamyx** — современная, красивая и полностью функциональная игровая платформа для **Telegram Mini Apps**. Пользователи соревнуются в динамичных мини-играх прямо внутри Telegram, зарабатывают монеты **Gamyx Coins**, получают XP и повышают уровни, забирают ежедневные бонусы и поднимаются в рейтинге.

---

## 🌟 Основные возможности

### 1. Премиальный игровой интерфейс
- **Dark Theme Gaming UI**: глубокий графитовый фон (`#080910`), фиолетовые, неоновые синие и золотые акценты.
- **Glassmorphism & Glow Effects**: мягкое неоновое свечение, стекло с размытием (`backdrop-filter: blur`), плавные переходы.
- **Адаптивность**: полноценная поддержка смартфонов (iOS, Android с учетом Safe Areas) и десктопа.
- **Telegram SDK Integration**: тактильная отдача (Haptic Feedback) на каждое игровое действие, нативная кнопка Telegram `BackButton`, автоматическое получение профиля Telegram и адаптация темы.

### 2. Полный каталог из 8 играбельных мини-игр
1. 🐍 **Neon Snake**: классическая неоновая змейка с золотыми бонусными яблоками, сенсорным D-pad / свайпами и множителями скорости.
2. 🧩 **2048 Cyber**: головоломка слияния силовых плиток 4x4, плавной анимацией, кнопкой Undo и свайп-управлением.
3. 💣 **Gamyx Mines**: хит Telegram Mini Apps! Сетка 5x5 с выбором количества мин (1-10) и ставки монет. Открывайте алмазы для роста множителя (до 24x) и вовремя нажимайте **Cash Out** до взрыва бомбы!
4. 🃏 **Cyber Memory**: тренировка памяти с 16 голографическими карточками (8 пар игровых реликвий), таймером и счетчиком ходов.
5. ⚡ **Reflex Arena**: испытание скорости реакции на миллисекунды. Замеряет 3 раунда, рассчитывает среднее время и выставляет рейтинг от "Casual" до "Godlike (< 200ms)".
6. 🔥 **Tap Rush 15s**: 15-секундный скоростной кликер со счетчиком CPS (кликов в секунду), комбо-эффектом Turbo Mode (2x множитель) и вылетающими партиклами.
7. ⚔️ **Neon XO Duel (Tic-Tac-Toe)**: крестики-нолики против умного ИИ-бота с неоновыми лазерными линиями победы и множителем за победные серии.
8. 🪨 **Cyber RPS (Камень, Ножницы, Бумага)**: быстрая дуэль против бота с механикой комбо-серий побед и историей последних раундов.

### 3. Игровая экономика и система прогресса
- 🪙 **Gamyx Coins**: внутренняя валюта, зарабатываемая за победы в играх, выполнение заданий и ежедневные награды.
- ⭐ **XP & Leveling System**: прогрессия уровней (1 → 100+) с формулой масштабирования, бонусами монет при Level Up и модальным окном поздравления.
- 🎁 **7-Day Daily Bonus**: интерактивный трекер стрика с растущими ежедневными наградами (до 500 монет на 7-й день) и конфетти.
- 🎯 **Система квестов**:
  - Ежедневные задания (с таймером обратного отсчета).
  - Еженедельные задания.
  - Мгновенный клейм наград с уведомлениями.
- 🏆 **Система достижений (Badges)**: 8 уникальных бейджей ("Crypto Whale", "Bomb Defuser", "Superluminal", "Quantum Merger" и др.).
- 📊 **Таблица лидеров (Leaderboard)**: разделы "По уровню", "По монетам" и "По рекордам игр", золотой/серебряный/бронзовый пьедестал и закрепленная плашка с позицией текущего игрока.
- 👤 **Профиль игрока**: аватар Telegram, Telegram ID, статистика матчей, винрейт, личные рекорды по всем 8 играм, история недавних матчей, переключатели звука и виброотклика.

### 4. Безопасность Telegram
- 🔒 **Server-Side HMAC-SHA256 Verification**: бэкенд на Express проверяет криптографическую подпись `initData` по алгоритму Telegram WebApp, защищая от подделки пользовательских данных.

---

## 🛠 Технологический стек
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS 4, Framer Motion, Lucide Icons, Canvas-Confetti
- **State Management & Persistence**: Zustand с LocalStorage persist middleware
- **Telegram SDK**: window.Telegram.WebApp (Haptics, BackButton, Viewport, Theme)
- **Backend**: Node.js, Express, CORS, Crypto (HMAC-SHA256 signature check), JSON/SQLite storage

## 🚀 Запуск и разработка

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки (Vite)
```bash
npm run dev
```
Приложение откроется на `http://127.0.0.1:5173`.

### 3. Проверка типов TypeScript
```bash
npm run typecheck
```

### 4. Сборка для продакшена
```bash
npm run build
```

### 5. Запуск полного сервера (Backend + Frontend)
```bash
npm start
```
Сервер запустится на `http://127.0.0.1:3001` и будет отдавать как API (`/api/auth/telegram`, `/api/leaderboard`, `/api/score`), так и собранный клиент.

## 📱 Интеграция с Telegram BotFather
1. Откройте `@BotFather` в Telegram и выполните `/newbot`.
2. Создайте Mini App через команду `/newapp`.
3. Укажите публичный HTTPS URL вашего развернутого приложения (например, `https://your-domain.com`).
4. Задайте short name, например `gamyx`.
5. Теперь платформа доступна по ссылке `t.me/your_bot/gamyx` прямо внутри Telegram!
